Set up & run

Requires Node.js on your host device. Pick either method below:

  1. Clone the repository and enter the folder.
  2. Install dependencies with npm install and start with node server.js.
  3. Open the printed local URL on any device on the same Wi-Fi.
git clone https://github.com/yasin786-my/ShaLo.git
cd ShaLo
npm install
node server.js
  1. Download the ZIP (click here) and extract it.
  2. Open a terminal inside the extracted folder, run npm install, then start with node server.js.
  3. Open the printed local URL on any device on the same Wi-Fi.
cd ShaLo-main
npm install
node server.js

Phone to phone

With a laptop

Run the server on the computer, then open its address on both phones.

Without a laptop (Android)

One Android can host with Termux:

  • pkg install nodejs
  • cd ShaLo && npm install
  • node server.js

Keep Termux open. iPhones can send & receive but can’t host.

No Wi-Fi

Turn on the host phone’s hotspot and join it from the other phone.

Command line

No browser? Use curl:

  • curl -F "files=@photo.jpg" http://…/upload
  • curl http://…/api/files

Security note

ShaLo has no password. Anyone on the same network can send and download files. Use it on networks you trust, not public Wi-Fi. Files stay in the shared/ folder on the host until you delete them.
